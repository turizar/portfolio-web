# Assets for Kidney Segmentation project page

Add these files **in this folder** so the project page loads them:

1. **segmentation-overlay-kidney.webp**  
   Your overlay image for the hero and video poster.  
   - If your file is named `segmentation_overlay_kidney.webp` or `segemntation_overlay_kidney.webp`, rename it to: `segmentation-overlay-kidney.webp`

2. **kidney-demo.mov**  
   Your screen recording for the Demo section.  
   - Rename your file (e.g. `Screen Recording 2026-01-10 at 1.40.53 PM.mov`) to: `kidney-demo.mov`

Paths from project root:
- `public/projects/kidney-segmentation/segmentation-overlay-kidney.webp`
- `public/projects/kidney-segmentation/kidney-demo.mov`
